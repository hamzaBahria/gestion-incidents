# Gestion des incidents informatiques

Application web (Flask + SQLite) pour gérer les incidents signalés
par les étudiants et les enseignants.

## Fonctionnalités
- Ajouter un incident
- Afficher la liste des incidents
- Consulter les détails d'un incident
- Modifier le statut (nouveau, en cours, résolu)
- Supprimer un incident

## Technologies
Python, Flask, SQLite, Docker, Docker Compose, GitHub Actions, GHCR

## Lancer en local
    python -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    python run.py

Application disponible sur http://localhost:5000
